# Associative Memory Proteomics

Analysis code for the Associative Memory Proteomics data set: laser-captured samples of four
sample classes from 12 mice in four conditions.

The code is in [`proteomic_analysis/`](proteomic_analysis/). Its
[README](proteomic_analysis/README.md) covers installation, the demo, the pipeline, the tests
and the data release.
